# Calculator

A simple command-line calculator built using C.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Power
- Square Root
- Percentage
- Division by zero protection
- Continuous calculations through a menu

## Technologies Used

- C
- GCC

## How to Run

Compile the program using:

```bash
gcc main.c -o calculator -lm\
